# Avatar Images Folder

Drop your custom avatar images here for use in the AI Review Generator.

## How to use:
1. Add JPG/PNG avatar images to this folder (e.g., `avatar1.jpg`, `avatar2.png`)
2. The app will automatically pull from these images for review posts
3. Name them anything — they'll be picked at random

## Recommended image specs:
- Square images work best (e.g., 200x200 or 400x400)
- JPG or PNG format
- Realistic headshots look best for Facebook post credibility
